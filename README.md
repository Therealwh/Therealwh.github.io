# MTProxy Live — живой MTProto Web Proxy

**Рабочий MTProto Web Proxy для Telegram со статусом онлайн.** Страница сайта показывает реальную проверку доступности сервера, которая выполняется **GitHub Actions каждые 5 минут**, — статус «🟢 Работает» означает настоящее TCP-подключение к серверу, а не устаревшую надпись со случайного агрегатора.

## 🔗 Прокси


## 🌐 Сайт

**https://therealwh.github.io/**

На сайте: живой индикатор доступности, время отклика, uptime по истории проверок, кнопки «Подключить / Скопировать / Поделиться», инструкция подключения за 30 секунд, 4 баннера сервисов (бесплатные прокси, приватный прокси, канал, обход блокировок Discord/YouTube).

## ⚙️ Как работает проверка

- GitHub Actions запускается по cron `*/5 * * * *` (каждые 5 минут)
- `check.py` выполняет TCP-подключение к `tgchat.run:443` с таймаутом 8 секунд и замером времени отклика
- Результат пишется в `status.json`, история (последние 1000 проверок) — в `history.json`
- Ежедневно обновляются даты в `<title>`, `<meta description>` и тексте страницы (SEO-свежесть)
- Коммит делается только при изменениях
